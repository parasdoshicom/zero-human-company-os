# Operating templates

Copy these into your private workspace. Replace placeholders with owner-approved facts. A template never grants permission to act.

- [Company brief](brief.md)
- [Bounded task](task.json)
- [Evidence record](evidence.json)
- [Experiment](experiment.md)
- [Tool switch trial](switch-trial.md)
- [Daily review](daily-review.md)

Every consequential record needs a source and observation time. Keep observations, assumptions, and decisions distinct.
