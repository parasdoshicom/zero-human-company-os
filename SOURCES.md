# Sources and provenance

## Primary published source

Paras Doshi, [9 learnings from running a Tiny AI Company](https://www.insightextractor.com/p/dont-spend-5000-on-an-ai-course-start), August 17, 2026; reviewed October 15, 2026. The article reports operating experience and limitations, not a controlled comparison. This repository implements original starter code and templates around the author's requested operating lessons; it does not reproduce the article.

## Additional author input

Paras supplied the five-judgment teaching order and tool-switching experience for the October 15, 2026 Bell AI presentation. The Hermes timeline and access difficulties are his firsthand assessment. This repository does not establish causation for platform restrictions, verify vendor capacity promises, or publish private operational records.

## Design references

[Shubham Saboo's public GitHub profile](https://github.com/Shubhamsaboo) was requested as inspiration for approachable, useful public repositories. No source code or branded assets were copied. [P Stack by Lauren Tan (@poteto)](https://github.com/cursor/plugins/tree/main/pstack) inspired the organization of principles as reusable files and practical rules; this repository uses original wording and implementation. The Company Stack organizes its own principles as individual, challengeable operating rules.

All example companies, events, purchases, prices, names, and task results in the runnable demo are fictional. Dates in fixtures are fixed for reproducibility. No real customer records or account credentials are included.
